# Health LLM Chatty App

An AI-powered healthcare chat application frontend built with Expo, React Native, TypeScript, NativeWind, and TailwindCSS.

## Features

- Modern mobile chat UI
- Clean responsive design
- Expo Router architecture
- TypeScript support
- TailwindCSS + NativeWind styling
- Reusable component structure
- Cross-platform support (Android / iOS)

## Tech Stack

- React Native
- Expo
- TypeScript
- NativeWind
- TailwindCSS

## Project Structure

```bash
app/
components/
assets/
```

## Installation

```bash
git clone https://github.com/NayefNagib/health-LLM-chatty-app.git

cd health-LLM-chatty-app

npm install

npx expo start
```
